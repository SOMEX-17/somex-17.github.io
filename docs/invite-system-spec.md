# TOPBARBERS.NET — закрытая система приглашений (ТЗ v1.1)
Дата: 2026-11-24. Статус: проектирование, НЕ запущено.

## Неприкосновенные требования
- Публичный дизайн, тексты, карточки, стили, отступы и действующие ссылки записи YCLIENTS сохраняются.
- На главной странице нет кнопки «Стать мастером» и публичной регистрации.
- Клиент записывается непосредственно через персональную ссылку мастера; TOPBARBERS не собирает данные записи.
- Публикация любого нового/изменённого профиля только после модерации владельца.
- Без согласия владельца не подключать платные услуги и не переносить домен/хостинг.
- Данные российских граждан, включая черновики, согласия, файлы и резервные копии, не помещать в зарубежную БД до юридической проверки локализации и трансграничной передачи.

## Приглашения
- Одна общая ссылка для приглашённой группы: /invite/<random-token>, без публичной навигации.
- Токен 256 бит, CSPRNG, в БД только SHA-256; не логировать сырой токен.
- Срок 5 дней по UTC; можно досрочно отозвать или выпустить новый.
- Многократное использование в срок действия, но каждый мастер получает отдельный ID заявки и отдельную приватную сессию.
- Погашение общей ссылки НЕ происходит после первой анкеты.
- Истёкшее приглашение запрещает новые анкеты, но не уничтожает уже поданные заявки.
- Доступ к черновикам через отдельную защищённую сессию, не через общий токен. Для MVP допустимо не поддерживать восстановление черновика после закрытия браузера; это явно сообщается мастеру.
- Ограничение частоты, проверка Turnstile на сервере, лимиты размеров и количества файлов, защита от повторных отправок, идемпотентность.
- Referrer-Policy: no-referrer; Cache-Control: no-store; X-Robots-Tag: noindex, nofollow; не помещать токен в аналитику, сторонние скрипты, реферер и логи.
- Перед публикацией владелец сверяет личность и профессиональные работы с приглашённым человеком.

## Анкета
1. Публичное профессиональное имя, стаж, специализация, описание.
2. Город, адреса мест работы, координаты (только после проверки адреса).
3. Аватар и портфолио; серверная проверка MIME по содержимому, ограничение размера/разрешения, преобразование изображений, удаление EXIF.
4. Ссылка YCLIENTS или иная согласованная ссылка записи; разрешать только HTTPS и проверять допустимые домены.
5. Отдельные подтверждения: обработка данных, публикация/распространение данных, права на фотографии и разрешение изображённых лиц; версия текста, время, ID заявки, доказательство согласия.
6. Контакт для организационной связи с мастером, НЕ отображаемый публично без отдельного согласия.
7. Предпросмотр карточки в существующем стиле.
Не собирать паспортные данные, дату рождения и другие лишние сведения.

## Модерация
Статусы: draft -> submitted -> in_review -> approved/rejected/changes_requested; approved -> published; published -> hidden/archived. Каждое изменение статуса журналируется.
- Только владелец через защищённую аутентификацию (MFA желательно).
- Таблица заявок: дата, имя, город, статус; фильтры; просмотр материалов и согласий.
- Одобрить, отклонить с причиной, вернуть на исправление, скрыть опубликованный профиль, отозвать приглашение.
- Все изменения опубликованных профилей сначала идут в отдельную версию на модерацию. Старый профиль остаётся до одобрения.
- Приватные анкеты и файлы недоступны посетителям и поисковикам.

## Архитектура
Публичный сайт: текущий GitHub Pages + Cloudflare DNS, без переноса домена.
Сервер анкет/админки: отдельный API и хранилище в РФ (выбор провайдера после проверки договора, физического размещения, резервных копий, обработки и стоимости).
DNS: например, admin.topbarbers.net и api.topbarbers.net направить на сервер РФ. Не менять apex без необходимости.
Публикация: из одобренных записей генерировать валидированный JSON-каталог и подключать к текущему UI через минимальный адаптер; обеспечить откат и резервный снимок. Проверить трансграничную передачу и публичное распространение до загрузки данных на GitHub Pages/CDN.
Существующий массив MASTERS содержит профили и отзывы; нужна миграция с сохранением идентификаторов, карточек, координат, фильтров, карты, ссылок и порядка. Не выдумывать отзывы и рейтинги.

## Минимальная модель данных
invitation(id, token_hash, created_at, expires_at, revoked_at, label)
application(id, invitation_id, status, created_at, updated_at, submitted_at)
master_profile(id, application_id, public_name, experience, specialization, bio, booking_url, version)
location(id, master_id, city, address, latitude, longitude, sort_order)
media(id, application_id, object_key, media_type, sort_order, moderation_status)
consent(id, application_id, consent_type, text_version, accepted_at, evidence_ref)
moderation_event(id, application_id, actor_id, action, reason, timestamp)
publication(id, master_id, version, published_at, hidden_at)
Все операции через серверную авторизацию и параметризованные SQL-запросы; резервное копирование, сроки хранения и удаление по запросу.

## Безопасность и право
- HTTPS, CSRF защита для cookie-сессий, HttpOnly/Secure/SameSite, CSP, CORS allowlist, серверная проверка всех полей.
- Ограничение доступа к медиа до публикации, проверка загружаемых файлов, отсутствие исполняемого содержимого.
- Проверка 152-ФЗ, локализации первичного сбора, уведомления Роскомнадзора, трансграничной передачи и согласия на распространение; отдельно требования стран СНГ перед запуском в каждой стране.
- Не утверждать, что российский хостинг автоматически решает все вопросы передачи данных при использовании зарубежного CDN.
- Документы и тексты согласий утверждать до приёма реальных заявок.

## Приёмка
- Без токена / с истёкшим / отозванным токеном нельзя начать новую анкету.
- По действующей общей ссылке два разных мастера создают независимые заявки без доступа друг к другу.
- Заявка не публикуется до решения владельца.
- После одобрения профиль отображается в прежнем UI; карта, геолокация, фильтры и YCLIENTS работают.
- Отклонение, скрытие, редактирование и отзыв согласия не оставляют публичных данных там, где они должны быть удалены.
- Проверки на iPhone Safari, Android Chrome, desktop, узких экранах, доступность, скорость загрузки, отсутствие перекрытий и обрезанного текста.
- Проверить миграцию всех текущих мастеров без изменения дизайна и ссылок.
- Проводить запуск только после тестирования на отдельном окружении и явного подтверждения владельца.
