# Mobile UX standards

Owner feedback, 2026-11-25.
- Explicit open/preview actions must reveal their result in the viewport, scrolling vertically to newly opened content where necessary.
- All tabs, nested cards, catalogs and galleries must fit the viewport without horizontal scrolling. Constrain intrinsic widths, wrap long content and test at 320–430 CSS px. Do not disable accessibility zoom or agreed photo gestures.
- Verify on iPhone before acceptance; apply these standards to future public catalog changes too. v18 applies to prototype only.
